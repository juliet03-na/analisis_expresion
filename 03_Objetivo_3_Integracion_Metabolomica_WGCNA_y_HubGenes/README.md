# OE3 Integracion Metabolomica WGCNA y HubGenes

> Objetivo Específico 3 (Módulo 4): Curaduría forense de la matriz metabolómica (recuperación de 339 decimales en 76 alcaloides tropánicos + 3 precursores), construcción de redes de co-expresión génica WGCNA Signed (power=12, sin outgroup B19, 22 módulos finos / 9 macro-módulos consolidados, solo 8,10% en grey), correlación Módulo-Alcaloide (101 asociaciones significativas) y selección de los 1.440 Hub Genes candidatos de élite.

## Estructura de esta carpeta
- **`01_Scripts/`**: Scripts reproducibles de R y Python correspondientes a este objetivo.
- **`02_Tablas_CSV/`**: Matrices y tablas de resultados auditadas.
- **`03_Figuras_Publicacion/`**: Gráficos científicos en formatos `.svg`, `.png` y `.pdf`.
- **`04_Documentacion_LLMWiki/`**: Nodos técnicos de la base de conocimiento LLMWiki de la tesis.
