# OE2 Cuantificacion Normalizacion y DEGs

> Objetivo Específico 2 (Módulo 3): Cuantificación en Salmon v1.10.3, importación con corrección de longitud efectiva (tximport), embudo de filtrado estadístico en 7 pasos (123.099 -> 54.363 Pre-MAD -> 36.647 Post-MAD tras VST), diagnóstico multivariado (PCA y correlación de muestras con/sin B19) y expresión diferencial entre Subclado A (Alta Montaña) y Subclado B (Tierras Bajas).

## Estructura de esta carpeta
- **`01_Scripts/`**: Scripts reproducibles de R y Python correspondientes a este objetivo.
- **`02_Tablas_CSV/`**: Matrices y tablas de resultados auditadas.
- **`03_Figuras_Publicacion/`**: Gráficos científicos en formatos `.svg`, `.png` y `.pdf`.
- **`04_Documentacion_LLMWiki/`**: Nodos técnicos de la base de conocimiento LLMWiki de la tesis.
