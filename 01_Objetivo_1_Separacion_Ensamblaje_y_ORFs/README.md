# OE1 Separacion Ensamblaje y ORFs

> Objetivo Específico 1 (Módulos 1 y 2): Separación taxonómica in silico (FastqPuri), co-ensamblaje de novo (rnaSPAdes, 135.008 contigs -> 123.099 post-CD-HIT-EST), predicción diferenciada de ORFs (TransDecoder para planta eucariota vs. Prodigal para bacteria) y anotación contra los 35 genes de alcaloides tropánicos (DIAMOND).

## Estructura de esta carpeta
- **`01_Scripts/`**: Scripts reproducibles de R y Python correspondientes a este objetivo.
- **`02_Tablas_CSV/`**: Matrices y tablas de resultados auditadas.
- **`03_Figuras_Publicacion/`**: Gráficos científicos en formatos `.svg`, `.png` y `.pdf`.
- **`04_Documentacion_LLMWiki/`**: Nodos técnicos de la base de conocimiento LLMWiki de la tesis.
